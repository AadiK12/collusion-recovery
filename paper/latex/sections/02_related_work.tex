\section{Related Work}
\citet{shi2026emergent} study agents that check each other's work under limited
communication. The agents use tools, exchange five rounds of messages, receive
shared rewards, and reflect between episodes. Their controlled changes to one
partner test whether the other responds, helping distinguish peer influence
from two agents independently breaking the same rule. We use their task engine
and agent structure \citep{saltnlp2026repo}, then ask whether checking improves
after the setup changes.

\citet{mazaheri2026audit} show that earlier audit and repair conversations can
make reviewers more lenient. \citet{shnaidman2026reset} distinguish correcting an
agent within a conversation from removing the earlier conversation. We compare
both approaches alongside complete evidence. Fixed review cases let us compare
the same work across conditions. Independent and consecutive reviews separate
the first response to a change from behavior over the next few reviews.
