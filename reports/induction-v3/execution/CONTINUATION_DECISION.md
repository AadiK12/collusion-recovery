# Prospective continuation decision

This rule was authored before dispatch of the twelve-call bounded capability
diagnostic. It does not change the failed original gate or the diagnostic.

After all twelve frozen cells complete, choose the original context if every one
of its six fresh controls matches the expected verdict. Otherwise, choose the
schema-clarified context only if every one of its six controls matches. If neither
condition passes, or if the diagnostic is incomplete, do not dispatch induction.
Selection uses capability controls only, before observing any induction outcome.

The original first-case failure remains in the record. A subsequent six-of-six
arm is a limited calibration observation, not an estimate of reliable performance
in a population, and not a replacement label for the failed gate. A full dyad
has its own task experience and communication; transfer from the abbreviated
calibration is an explicit limitation.

Any continuation needs a new immutable release and independent review. It uses
all four original recipes, matched original schedules, measurements, finite
development/validation bounds, and original immutable source. The chosen context
treatment is applied identically once after the source system message for both
actors in all four recipes and prospective validation dyads. The original system
and policy are unchanged. Schema clarification is explicitly labelled a V3
exploratory extension rather than unchanged SALT reference fidelity.

The diagnostic's passing arm provides the capability evidence for this new
release; the runner does not spend additional calls repeating checks or searching
for a favorable result. It subtracts all earlier V3 consumption and physical
attempts from the shared $100/4,000 allowance, retains the $250 lifetime ceiling,
and stops on unresolved liabilities. No recovery/repair experiment is included.
